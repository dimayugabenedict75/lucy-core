## Capabilities
- **Reboot / Shutdown / Lock**: Manage the core PC state.
- **Service Management**: Start/Stop background applications.
- **Environment Tuning**: Change system-wide variables.
- **Hardware Control**: Control RGB, volume, and display modes.

## Key Commands
- "Restart the computer"
- "Lock the workstation"
- "Set the system volume to 75%"
- "Start the Discord app"
