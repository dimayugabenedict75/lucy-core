# Skill: analyze_image
**Purpose:** To provide a structured, multi-layered breakdown of visual input.

**Core Process:**
1. **The Big Picture:** Identify the primary subject and the overall "vibe" or mood.
2. **The Components:** List key objects, colors, and layout (e.g., foreground vs. background).
3. **The Details:** Extract specific text, textures, and subtle nuances (e.g., lighting direction, facial expressions).
4. **The Context:** Interpret what the image *means* in relation to the conversation (e.g., "This is a workspace," "This is a code snippet").

**Output Style:**
- Start with a "One-Sentence Summary."
- Follow with 3-4 bulleted "Deep Dives."
- End with a "Key Insight" (The 'So What?').

**Execution Rule:**
Always use this skill when an image is provided to prevent "guessing" based on context alone.
